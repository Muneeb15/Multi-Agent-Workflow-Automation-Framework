# Agents Overview — How These Two Projects Help You

---

## Project 1: agency-agents

**What it is:** A collection of ready-made AI agent personalities (markdown files) you drop into Claude Code, Cursor, Copilot, Windsurf, or other AI tools. Each file gives an AI a specialized role, personality, and workflow.

**How it helps you:** Instead of writing prompts from scratch, you activate a pre-built expert. You get deep domain knowledge, a defined communication style, and real deliverables — not generic answers.

## Project 2: Ruflo (formerly Claude Flow)

**What it is:** A multi-agent orchestration framework that plugs into Claude Code. It gives Claude Code a coordination layer — agents self-organize into swarms, share memory, learn from past tasks, and can collaborate across machines.

**How it helps you:** You stop manually managing which agent does what. Ruflo routes tasks intelligently, remembers context across sessions, runs background workers automatically, and lets you scale to 100+ agents working in parallel.

---

### Core Capabilities

| Capability | How it helps you |
|-----------|-----------------|
| **Swarm Coordination** | Runs multiple agents as a team with shared context and consensus — no manual orchestration |
| **Self-Learning Memory** | Agents remember successful patterns across sessions via HNSW vector search (150x faster than brute force) |
| **Autopilot Mode** | Agents run autonomously in a loop — you describe a goal, Ruflo executes it |
| **Background Workers** | 12 auto-triggered workers handle audits, test gap detection, optimization, and more without you asking |
| **Goal Planner (goal.ruv.io)** | Type a plain-English goal, get an A* action plan broken into agent tasks with a live dashboard |
| **Web UI (flo.ruv.io)** | Multi-model chat with ~210 MCP tools, parallel tool execution, and persistent memory — no install needed |
| **Multi-Provider LLM Routing** | Routes between Claude, GPT, Gemini, Cohere, and Ollama with intelligent failover |
| **Agent Federation** | Agents on different machines collaborate securely with zero-trust mTLS — useful for team or cross-org workflows |
| **Cost Tracker** | Tracks token usage, sets budgets, and sends cost alerts |

## How They Work Together

| Use Case | What to use |
|----------|-------------|
| You need a specialized expert for a one-off task | Pick an **agency-agents** agent and activate it in your AI tool |
| You want agents to coordinate on a complex project | Use **Ruflo swarm** to orchestrate multiple agents in parallel |
| You want persistent memory across sessions | Use **Ruflo agentdb + rag-memory** |
| You want agents to run automatically in the background | Use **Ruflo autopilot + loop-workers** |
| You want to plan a big goal and let agents execute it | Use **Ruflo goal planner at goal.ruv.io** |
| You want to collaborate with agents across machines or teams | Use **Ruflo federation** |
| You want pre-built expert personalities without infrastructure | Use **agency-agents** alone |
| You want full autonomous multi-agent orchestration | Use **Ruflo** with agency-agents definitions loaded in |
