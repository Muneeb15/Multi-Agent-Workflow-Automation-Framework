## 🎯 How to Use It (3 Simple Ways)

### **Option 1: Copy-Paste Prompt** (Easiest — 30 seconds)

1. Open `integrated-agents/ACTIVATION-PROMPT.txt`
2. Copy the entire prompt
3. Paste into Claude Code, Cursor, Copilot, or any AI tool
4. Add your task at the end
5. Press Enter

**Example:**
```
[Paste the activation prompt]

NOW ACTIVATE AUTONOMOUS MODE AND COMPLETE THIS TASK:
Build a React dashboard with dark theme and user authentication
```

✅ The orchestrator will handle everything and notify you when done!

---

### **Option 2: CLI Runner** (For Automation)

```bash
cd integrated-agents
node run-task.js "YOUR TASK HERE"
```

**Examples:**
```bash
node run-task.js "Build a landing page with pricing table"
node run-task.js "Audit API for security vulnerabilities"
node run-task.js "Create 30-day TikTok content calendar"
```

---

### **Option 3: Web UI** (Visual Interface)

```bash
cd integrated-agents/frontend
npm install
npm run dev
```

Then open: http://localhost:3000

**Features:**
- Browse all 337 agents visually
- Search and filter
- View agent details
- Chat interface
- View Ruflo plugins
